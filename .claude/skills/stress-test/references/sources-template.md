# Stress-test sources

Where source material lives on this machine, by job or topic. The stress-test skill reads this file to find evidence when you don't name sources yourself.

Save it as either:
- `.claude/stress-test-sources.md` inside a project, for that project only
- `stress-test-sources.md` in your home `.claude` folder (`~/.claude/` on Mac and Linux, `%USERPROFILE%\.claude\` on Windows), for everything on this machine

If both exist, the project file is checked first.

Add one section per job or topic. Say in the heading when the section applies, then list files, folders, URLs, ticket projects, wiki spaces, or tools to search. Paths are specific to each machine, so each machine keeps its own copy.

## Example: Acme billing work (use for anything about Acme, the billing migration, or tickets in Jira project BILL)
- C:\Work\Acme\handoff.md
- C:\Work\Acme\docs\
- Jira project BILL
- Confluence space ENG

## Example: Household finances (use for budgets, taxes, and insurance questions)
- ~/Documents/finance/
- ~/Documents/insurance/policies.pdf
